\# BitTable F1 - Frequent Itemset Mining



Ứng dụng Streamlit mô phỏng thuật toán BitTable F1.



\## Chức năng



\- Đọc dữ liệu giao dịch

\- Upload file CSV

\- Chuyển dữ liệu sang biểu diễn bit

\- Tạo Vector Bit dọc

\- Sinh L1

\- Sinh C2 → L2

\- Sinh C3 bằng MID → L3

\- Sinh C4 bằng MID → L4

\- Tổng hợp các tập phổ biến



\## Dữ liệu mẫu



MinSup = 50%



Kết quả:



\- L1 = 5

\- L2 = 8

\- L3 = 5

\- L4 = 1

\- Tổng = 19 tập phổ biến
